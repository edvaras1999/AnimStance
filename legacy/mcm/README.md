# MCM antigo (v0.2.0) - guardado, nao compilado

O menu agora e o KHA-OS (plugin SKSE), por isso o MCM em Papyrus, os `Stubs` do SkyUI e o
compilador Caprica ja nao fazem parte do build. Ficam aqui so como referencia.

(o gerador `tools/make_esp.py` ja nao o cria) e os `Stubs` precisam declarar os eventos do SkyUI.
